# ⚽ نظام إدارة وتشغيل ملعب الأحمدية الخماسي (AHMADIAH PITCH MANAGER)

> **نظام تشغيل وإدارة وحجز متكامل للملعب الخماسي بمركز شباب الأحمدية**  
> يجمع بين الحجز اللحظي المباشر، والتسعير الذكي (نهاري/ليلي)، ومراقبة الوقت بالعد التنازلي الحي، وشاشة عرض سينمائية للملعب، ونظام إدارة مالية دقيق، وإشعارات تلقائية عبر بوت تيليجرام، وتطبيق ويب تقدمي (PWA) قابل للتثبيت على الهواتف.

---

## 🌟 الميزات الرئيسية للنظام

1. **واجهة الحجز المباشرة (Public Booking Interface):**
   - ساعة رقمية مباشرة بتوقيت جمهورية مصر العربية (`Africa/Cairo`).
   - جدول تفاعلي لحظي لحالة الساعات:
     - 🟢 **أخضر (قابل للحجز):** الموعد متاح وجاهز.
     - 🔴 **أحمر (محجوز ومؤكد):** الملعب محجوز والمباراة جارية أو قادمة.
     - 🟡 **أصفر (في انتظار التأكيد):** طلب حجز مرسل وينتظر موافقة الإدارة.
     - 🟠 **برتقالي (انتهى الحجز):** انتهى وقت المباراة ويتطلب مراجعة.
   - نافذة حجز ذكية مع حساب السعر التلقائي ومنع التعارض والتداخل.

2. **نظام التسعير الذكي (نهاري / ليلي):**
   - احتساب تكلفة الساعات وفق التوقيت المحلي المصري بدقة.
   - تقسيم الحجوزات التي تعبر وقت الغروب (ساعات النهار بسعر، وساعات الليل بالكشافات بسعرها المخصص تلقائياً).

3. **العد التنازلي الحي (Live Countdown Timer):**
   - مؤشر وقت حي للمباراة الجارية بالثواني والدقائق ونسبة الإنجاز.
   - تنبيه صوتي ومرئي لحظة انتهاء الوقت وإخلاء أرضية الملعب.

4. **شاشة الملعب التفاعلية (`display.html` - Live Stadium Display):**
   - شاشة عرض ذات تباين عالي مخصصة لشاشات التلفزيون والتابلت داخل مركز الشباب.
   - عرض المباراة الحالية بعد تنازلي عملاق، مع تفاصيل المباراة القادمة والمواعيد المتاحة.

5. **لوحة تحكم المدير العام (`admin/index.html`):**
   - إمكانية تغيير كلمة مرور الإدارة من الإعدادات بكل سهولة.
   - مؤشرات لحظية (KPIs) للإيرادات، الحجوزات، الساعات المحجوزة، والساعات المتاحة.
   - إدارة كاملة للحجوزات (الموافقة، الحجز اليدوي، التعديل، التحصيل الجزئي، الإلغاء، الحذف).
   - سجل تدقيق العمليات (Audit Logs).

6. **نظام الحسابات والمالية الدقيق:**
   - تقارير يومية وشهرية آلية بالكامل مع تطبيق المعادلة المالية الصحيحة:
     $$\text{صافي الدخل} = \text{إجمالي النقدية المحصلة فعلياً} - \text{إجمالي المصروفات}$$
   - سجل المصروفات مصنفة (كهرباء، كشافات وإنارة، صيانة، نظافة، معدات، نثريات).
   - رسوم بيانية تفاعلية وتصدير التقارير إلى ملفات **Excel / CSV** تدعم اللغة العربية.

7. **بوت تيليجرام التلقائي (Telegram Notification Bot):**
   - أوامر عامة للمشتركين: `/start`, `/subscribe`, `/unsubscribe`, `/today`, `/available`, `/help`.
   - تنبيهات تلقائية لحظة تأكيد الحجز، إلغاء الحجز، أو انتهاء وقت المباراة.

8. **تطبيق ويب تقدمي (PWA):**
   - قابل للتثبيت كأيقونة تطبيق مستقل على أجهزة Android و iPhone والكمبيوتر.
   - شريط تنقل سفلي للهواتف (Mobile Bottom Navigation).
   - دعم كامل لوضع عدم الاتصال (Offline Mode) مع لافتة تحذيرية ذكية.

---

## 🛠️ البنية التقنية (Tech Stack)

- **الواجهة الأمامية:** HTML5, CSS3 (Modern Dark Stadium Glassmorphism), Vanilla JavaScript (ES Modules).
- **قاعدة البيانات:** Firebase Realtime Database (الوحيدة المعتمدة للتخزين والتحديث اللحظي).
- **الخادم السحابي:** Firebase Cloud Functions (Node.js 18) للتحكم في بوت تيليجرام ومراقبة انتهاء الوقت.
- **التصميم:** Mobile-First, 100% RTL مع خط Cairo و Tajawal.

## 🚀 طريقة التثبيت والتشغيل

### 1. إعداد ونشر واجهة الويب على GitHub Pages:
1. ارفع مجلد المشروع إلى مستودع GitHub:
   ```bash
   git add .
   git commit -m "إطلاق نظام إدارة وتشغيل ملعب الأحمدية الخماسي"
   git push origin main
   ```
2. في إعدادات المستودع (Settings -> Pages):
   - اختر فرع `main` والمجلد `/ (root)`.
   - سيصبح الموقع متاحاً مباشرة عبر الرابط الخاص بك.

### 2. إعداد Firebase Realtime Database:
قاعدة البيانات مهيأة مسبقاً في ملف `js/firebase-config.js` وفق إعدادات المشروع `hagz-a49fa`.  
لنشر قواعد الأمان:
```bash
firebase deploy --only database
```

### 3. إعداد ونشر بوت تيليجرام (اختياري للإشعارات):
1. افتح تطبيق تيليجرام وتواصل مع `@BotFather`.
2. أنشئ بوتاً جديداً عبر `/newbot` واحصل على `BOT_TOKEN`.
3. قم بتعيين Webhook عبر الأمر:
   ```bash
   curl -F "url=https://YOUR_REGION-hagz-a49fa.cloudfunctions.net/telegramWebhook" https://api.telegram.org/bot<YOUR_BOT_TOKEN>/setWebhook
   ```
4. لنشر الدوال السحابية:
   ```bash
   cd functions
   npm install
   firebase deploy --only functions
   ```

### 4. تسجيل دخول لوحة الإدارة:
- افتح الرابط: `admin/index.html`
- أدخل كلمة المرور المبدئية: `521988`
- يمكنك تغيير كلمة المرور فوراً من تبويب **"إعدادات النظام"**.
